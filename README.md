# Iterative Tomographic Image Reconstruction

A MATLAB implementation of an iterative tomographic image reconstruction algorithm designed to recover a 2D image from projection measurements acquired at multiple angles.

The reconstruction combines iterative least-squares optimization, Total Variation regularization, box constraints, and edge-preserving post-processing to produce stable reconstructions from sparse or noisy projection data.

## Features

- Iterative tomographic reconstruction
- Matrix-free forward and adjoint projection operators
- Conjugate Gradient optimization
- Total Variation regularization
- Huber-style adaptive TV weighting
- L2 regularization
- Box-constrained reconstruction
- Sparse-angle reconstruction support
- Noise-aware regularization
- Adaptive parameter selection based on problem size
- Edge-preserving smoothing
- Cached projection geometry
- Runtime-aware stopping criteria

---

## Reconstruction Model

The reconstruction problem can be interpreted as minimizing an objective of the form:

**Data fidelity + TV regularization + L2 regularization**

where:

- The **data fidelity term** forces the reconstructed image to remain consistent with the measured projections.
- **Total Variation regularization** promotes spatial smoothness while preserving significant edges.
- **L2 regularization** stabilizes the numerical optimization.
- **Box constraints** enforce known lower and upper bounds on reconstructed pixel values.

Conceptually, the optimization solves:

`min_x ||Ax - b||² + λTV · TV(x) + λL2 · ||x||²`

subject to:

`x_min ≤ x ≤ x_max`

where:

- `x` is the reconstructed image.
- `A` is the forward projection operator.
- `b` contains the measured projection data.
- `λTV` controls Total Variation regularization.
- `λL2` controls L2 regularization.

## Input Structure

The main entry point is:

`reconstruct(prob)`

The `prob` structure contains the reconstruction parameters.

### Required Fields

| Field | Description |
|---|---|
| `prob.b` | Projection measurements |
| `prob.N` | Width and height of the reconstructed image |
| `prob.angles` | Projection angles |
| `prob.n_det` | Number of detector bins |

### Optional Fields

| Field | Default | Description |
|---|---:|---|
| `prob.sigma` | `0` | Estimated noise level |
| `prob.x_min` | `0` | Minimum allowed pixel value |
| `prob.x_max` | `Inf` | Maximum allowed pixel value |

The returned vector `x` contains the reconstructed `N × N` image in column-major vectorized form.

The function also returns:

`info.iters`

which contains the total number of iterative solver steps performed during reconstruction.

## Projection Geometry

The projection geometry is precomputed by:

`build_geom()`

Each pixel is mapped to a detector bin for every projection angle according to:

`s = x cos(θ) + y sin(θ)`

Detector coordinates are discretized into `n_det` bins covering the complete image domain.

Instead of recomputing this mapping during every optimization iteration, the implementation stores:

- Pixel indices participating in each projection
- Corresponding detector-bin indices

This cached geometry is reused by both the forward and adjoint operators.

---

## Forward Projection

The forward operator is implemented by:

`forward_cached()`

It computes an approximation of:

`b = A x`

For each projection angle, pixel values are accumulated into their corresponding detector bins.

The implementation uses MATLAB's `accumarray` to efficiently combine all pixel contributions belonging to the same detector.

The result represents the synthetic projection data generated by the current image estimate.

---

## Adjoint Projection

The adjoint operator is implemented by:

`adjoint_cached()`

It approximates:

`x = Aᵀ b`

Each detector value is propagated back to the image pixels associated with that detector bin.

The forward and adjoint operators allow the reconstruction algorithm to work with the imaging operator without explicitly constructing a large system matrix.

---

## Matrix-Free Optimization

The normal-equation operator is evaluated through:

`apply_ata_cached()`

which computes:

`Aᵀ A x + λx`

without explicitly constructing either `A` or `AᵀA`.

This matrix-free approach significantly reduces memory requirements for larger reconstruction problems.

---

## Initial Reconstruction

The algorithm starts by computing the backprojection:

`Aᵀb`

An initial step size is estimated using the relationship:

`α₀ = (Aᵀb)ᵀ(Aᵀb) / ((Aᵀb)ᵀ AᵀA(Aᵀb))`

The resulting initial estimate is projected onto the allowed intensity interval before entering the main optimization stage.

A short Conjugate Gradient warm-up is then performed using the data fidelity and L2 regularization terms.

---

## Conjugate Gradient Solver

The main optimization uses Conjugate Gradient iterations to solve the local regularized reconstruction problem.

For each search direction `p`, the algorithm evaluates an operator of the form:

`AᵀAp + λTV Lw(p) + λL2 p`

where `Lw` represents the weighted regularization operator.

The reconstruction is updated iteratively using:

`x ← x + αp`

while the residual determines the next conjugate search direction.

The inner optimization terminates when:

- The residual becomes sufficiently small
- Numerical instability is detected
- The configured iteration limit is reached
- The runtime budget is exhausted

---

## Total Variation Regularization

To improve reconstructions from sparse or noisy projection data, the implementation applies edge-aware Total Variation regularization.

Horizontal and vertical finite differences are computed for the current image.

The adaptive weights are calculated as:

`W = 1 / sqrt(Dx² + Dy² + γ²)`

where:

- `Dx` is the horizontal image gradient.
- `Dy` is the vertical image gradient.
- `γ` controls the smooth approximation near zero gradients.

The parameter `γ` is automatically adjusted according to the magnitude of the current reconstruction.

This weighting reduces smoothing across significant image boundaries while continuing to suppress smaller variations in relatively uniform regions.

---

## Weighted Regularization Operator

`apply_Lw()` implements the weighted spatial regularization operator.

The function:

1. Computes horizontal and vertical image differences.
2. Multiplies them by the adaptive Huber-style weights.
3. Computes the corresponding discrete divergence.
4. Returns the regularization contribution in vectorized form.

This operator is incorporated directly into the iterative solver.

---

## Box Constraints

Every major reconstruction update is followed by projection onto the valid intensity range using:

`project_box()`

The projection enforces:

`x_min ≤ x ≤ x_max`

Values below `x_min` are clipped to the lower boundary, while values above `x_max` are clipped when a finite upper bound is provided.

This is particularly useful when the reconstructed quantity is known to be non-negative or physically bounded.

---

## Adaptive Parameters

Optimization parameters are automatically selected according to:

- Image size
- Number of projection angles
- Angular sparsity
- Estimated noise level

Different configurations are used for small, medium, sparse-angle, and large reconstruction problems.

The algorithm adapts:

- Maximum runtime
- Number of outer iterations
- Number of Conjugate Gradient iterations
- L2 regularization strength
- Total Variation regularization strength

TV regularization is gradually reduced during optimization:

`λTV ← 0.96 · λTV`

This allows stronger stabilization during earlier reconstruction stages while progressively giving more weight to the measured data.

---

## Intensity Scaling

After iterative reconstruction, a global scaling factor is estimated from the reconstructed projections:

`scale = (Ax)ᵀb / (Ax)ᵀ(Ax)`

When the estimated factor is valid and positive, the reconstructed image is rescaled before the final post-processing stage.

This compensates for global intensity differences between the predicted and measured projection data.

---

## Edge-Preserving Smoothing

The final reconstruction is processed using a lightweight edge-preserving smoothing stage.

`edge_preserving_smooth()` estimates directional intensity differences between neighboring pixels:

- North
- South
- East
- West

Each direction receives an edge-dependent diffusion coefficient:

`c = exp(-(difference / κ)²)`

Large intensity differences therefore receive smaller weights, reducing diffusion across significant edges.

Small variations inside homogeneous regions receive larger weights and are smoothed more strongly.

The number of smoothing iterations is automatically adapted according to image size and the number of available projection angles.

---

## Reconstruction Pipeline

The complete reconstruction process is:

1. Read reconstruction parameters.
2. Build and cache projection geometry.
3. Select optimization parameters according to problem size and sparsity.
4. Compute the adjoint projection `Aᵀb`.
5. Generate an initial reconstruction.
6. Apply a Conjugate Gradient warm-up.
7. Compute adaptive TV weights.
8. Evaluate the projection residual.
9. Perform regularized Conjugate Gradient optimization.
10. Enforce box constraints after reconstruction updates.
11. Gradually reduce TV regularization.
12. Estimate and apply global intensity scaling.
13. Perform edge-preserving smoothing.
14. Apply the final intensity constraints.
15. Return the reconstructed image and iteration information.

## Computational Design

The implementation avoids explicitly constructing the complete tomography system matrix.

For an `N × N` image and a large number of measurements, such a matrix can become expensive to store and manipulate.

Instead, the reconstruction relies on operator-based computations:

`x → A x`

and:

`b → Aᵀ b`

Projection geometry is computed once and cached, allowing these operations to reuse the same pixel-to-detector mappings throughout the optimization.

This design reduces memory usage while keeping the reconstruction procedure suitable for iterative numerical optimization.
